Check "schema" is "release-intel.v1" and compare "headSha" with the SHA from 5a (ignore case).
   - Match: use it. Read riskTier, score.level, blockers[], model (the model the API reported), requestedModel, modelReported, and telemetry (promptTokens, completionTokens, latencyMs, estUsd, estNote).
   - Mismatch (another SHA), headSha missing or null, no comment, or the release-intel check on that SHA is still running: wait like step 3. If the check failed, or still nothing after the checks finish, record "none" with the reason (check failed / no comment / report is for another SHA / report has no headSha). Read the failed step's error line for the reason; never copy a secret.
   - Never use a report for another SHA as if it were this one. Never infer, estimate, round or fill in riskTier, blockers, model, tokens or cost yourself. Never write "low" because nothing was found. If telemetry fields are null, say "not reported".
