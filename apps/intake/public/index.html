1 What you need

Does this application already have a repository or codebase?

An enhancement changes something that already exists, so we need to be able to read its code. We ask this first, before the rest of the form.

An enhancement can't be acted on without an existing repository or codebase. If you are starting from scratch, choose New application or Website creation instead. Nothing will be submitted from this option.

Please give us read access.

  • GitHub: open the repository, then Settings, Collaborators, Add people. Invite the user vishamathur with the Read role. Organisation repositories offer Read; a personal repository only offers write access, so for those you may prefer to make the repository public for the review or copy it into an organisation.
  • Other hosts: invite the account vishamathur with the read-only role (GitLab: Members, role Reporter. Bitbucket: Repository settings, User and group access, Read). Release Desk can only confirm repositories that answer over HTTPS without signing in.

Then choose "I've granted access: check again". Your request can't be submitted until the repository is publicly readable. That does not mean you own it.
